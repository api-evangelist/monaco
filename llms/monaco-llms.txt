# Monaco Docs

## Docs

- [Beta Notice](https://docs.monaco.com/beta-notice.md)
- [Authentication](https://docs.monaco.com/auth.md)
- [Pagination, Sorting, and Filtering](https://docs.monaco.com/pagination-sorting-and-filtering.md)
- [List Contacts](https://docs.monaco.com/api-reference/contacts/list-contacts.md): Returns a paginated list of contacts.
- [Upsert a Contact](https://docs.monaco.com/api-reference/contacts/upsert-a-contact.md): Creates a new contact or updates an existing one.
- [Create a Contact](https://docs.monaco.com/api-reference/contacts/create-a-contact.md): Creates a new contact.
- [Get a Contact](https://docs.monaco.com/api-reference/contacts/get-a-contact.md): Gets a single contact by its `contact_id`. The detail response includes scoring, source attribution, and custom fields.
- [Delete a Contact](https://docs.monaco.com/api-reference/contacts/delete-a-contact.md): Deletes a contact by its `contact_id`. Returns 204 No Content on success. This is irreversible.
- [Update a Contact](https://docs.monaco.com/api-reference/contacts/update-a-contact.md): Updates an existing contact by its `contact_id`.
- [List Accounts](https://docs.monaco.com/api-reference/accounts/list-accounts.md): Returns a paginated list of accounts.
- [Upsert an Account](https://docs.monaco.com/api-reference/accounts/upsert-an-account.md): Creates a new account or updates an existing one. `domain` is the matching identifier.
- [Get an Account](https://docs.monaco.com/api-reference/accounts/get-an-account.md): Gets a single account by its `account_id`. The detail response includes enriched company information, scoring, and custom fields.
- [Delete an Account](https://docs.monaco.com/api-reference/accounts/delete-an-account.md): Deletes an account by its `account_id`. Returns 204 No Content on success. This is irreversible — associated contacts and opportunities are not deleted but may become unlinked.
- [Update an Account](https://docs.monaco.com/api-reference/accounts/update-an-account.md): Updates an existing account by its `account_id`.
- [List Opportunities](https://docs.monaco.com/api-reference/opportunities/list-opportunities.md): Returns a paginated list of opportunities.
- [Get an Opportunity](https://docs.monaco.com/api-reference/opportunities/get-an-opportunity.md): Gets a single opportunity by its `opportunity_id`. The detail response includes the AI-generated summary, identified risks, and custom fields.
- [Delete an Opportunity](https://docs.monaco.com/api-reference/opportunities/delete-an-opportunity.md): Deletes an opportunity by its `opportunity_id`. Returns 204 No Content on success. This is irreversible.
- [Update an Opportunity](https://docs.monaco.com/api-reference/opportunities/update-an-opportunity.md): Updates an existing opportunity by its `opportunity_id`.
- [Create an Opportunity](https://docs.monaco.com/api-reference/opportunities/create-an-opportunity.md): Creates a new opportunity associated with an existing account.
- [List Tasks](https://docs.monaco.com/api-reference/tasks/list-tasks.md): Returns a paginated list of tasks.
- [Get a Task](https://docs.monaco.com/api-reference/tasks/get-a-task.md): Gets a single task by its `task_id`.
- [Update a Task](https://docs.monaco.com/api-reference/tasks/update-a-task.md): Updates an existing task by its `task_id`.
- [Create a Task](https://docs.monaco.com/api-reference/tasks/create-a-task.md): Creates a new task.
- [List Tags](https://docs.monaco.com/api-reference/tags/list-tags.md): Returns every tag defined for the object type given by the `object` query parameter.
- [Create a Tag](https://docs.monaco.com/api-reference/tags/create-a-tag.md): Creates a new tag for the `object` given in the request body.
- [Get a Tag](https://docs.monaco.com/api-reference/tags/get-a-tag.md): Gets a single tag by its `tag_id`.
- [Delete a Tag](https://docs.monaco.com/api-reference/tags/delete-a-tag.md): Deletes a tag by its `tag_id`. The tag is removed from all entities it was applied to.
- [Update a Tag](https://docs.monaco.com/api-reference/tags/update-a-tag.md): Updates a tag's `name` and/or `color` by its `tag_id`. The object type of a tag cannot be changed.
- [List Meetings](https://docs.monaco.com/api-reference/meetings/list-meetings.md): Returns a paginated list of meetings.
- [Get a Meeting](https://docs.monaco.com/api-reference/meetings/get-a-meeting.md): Gets a single meeting by its `meeting_id`. The detail response includes the AI-generated summary, a presigned video URL, and the full transcript with speaker attribution.
- [List Sequences](https://docs.monaco.com/api-reference/sequences/list-sequences.md): Returns a paginated list of sequences.
- [Get a Sequence](https://docs.monaco.com/api-reference/sequences/get-a-sequence.md): Gets a single sequence by its `sequence_id`. The detail response includes the sequence's ordered list of tasks.
- [Update a Sequence](https://docs.monaco.com/api-reference/sequences/update-a-sequence.md): Applies a state transition to a sequence (see the `action` field for valid values and their meanings). Returns the refreshed sequence representation, including its tasks.
- [Update a Sequence Step](https://docs.monaco.com/api-reference/sequences/update-a-sequence-step.md): Updates the copy on a single step of a sequence. `step_id` is the `id` of the entry in the sequence's `tasks` list (from `get_sequence`). Supports `message` on email, InMail, LinkedIn message, LinkedIn connection-note, and gifting-email steps, and `subject` on email, InMail, and gifting-email steps.…
- [List Audiences](https://docs.monaco.com/api-reference/audiences/list-audiences.md): Returns a paginated list of audiences.
- [Get an Audience](https://docs.monaco.com/api-reference/audiences/get-an-audience.md): Gets a single audience by its `audience_id`.
- [List Audience Contacts](https://docs.monaco.com/api-reference/audiences/list-audience-contacts.md): Returns a paginated list of the contacts in an audience.
- [Add Contacts to Audience](https://docs.monaco.com/api-reference/audiences/add-contacts-to-audience.md): Adds one or more contacts to an audience by their IDs.
- [Create an Audience](https://docs.monaco.com/api-reference/audiences/create-an-audience.md): Creates a new audience, optionally seeded with contacts — either an explicit `contact_ids` list or a `filters` query over the contacts field schemas (optionally narrowed by `excluded_ids` or `source_audience_id`).
- [Remove Contacts from Audience](https://docs.monaco.com/api-reference/audiences/remove-contacts-from-audience.md): Removes the given `contact_ids` from an audience. Idempotent — IDs not in the audience are ignored. Any per-contact failures are returned in `failures`.
- [List Campaigns](https://docs.monaco.com/api-reference/campaigns/list-campaigns.md): Returns a paginated list of campaigns.
- [Get a Campaign](https://docs.monaco.com/api-reference/campaigns/get-a-campaign.md): Gets a single campaign by its `campaign_id`, including its attached audiences.
- [Update a Campaign](https://docs.monaco.com/api-reference/campaigns/update-a-campaign.md): Updates a campaign's content fields and/or transitions its lifecycle via `status`. Returns the refreshed campaign.
- [Create a Campaign](https://docs.monaco.com/api-reference/campaigns/create-a-campaign.md): Creates a campaign that enrolls the contacts of the given audiences onto a template, routing sends according to `distribution`.
- [Enroll Contacts in a Campaign](https://docs.monaco.com/api-reference/campaigns/enroll-contacts-in-a-campaign.md): Enrolls contacts into a campaign by creating a new audience named `audience_name`, attaching it to the campaign, and adding the contacts to it. The campaign must be `active` or `paused`.
- [Add Audiences to a Campaign](https://docs.monaco.com/api-reference/campaigns/add-audiences-to-a-campaign.md): Attaches the given audiences to a campaign, keeping its existing ones. Their contacts are enrolled asynchronously. Audiences already attached are ignored, so retries are safe. Returns the refreshed campaign.
- [Remove Audiences from a Campaign](https://docs.monaco.com/api-reference/campaigns/remove-audiences-from-a-campaign.md): Detaches the given audiences from a campaign, keeping the rest.
- [List Sequence Templates](https://docs.monaco.com/api-reference/sequence-templates/list-sequence-templates.md): Returns the list of sequence templates available to the authenticated organization.
- [Create a Sequence Template](https://docs.monaco.com/api-reference/sequence-templates/create-a-sequence-template.md): Creates a new sequence template. The template is created as a USER_GENERATED template.
- [Get a Sequence Template](https://docs.monaco.com/api-reference/sequence-templates/get-a-sequence-template.md): Gets a single sequence template by its `sequence_template_id`. The detail response includes the template's ordered list of steps.
- [Update a Sequence Template](https://docs.monaco.com/api-reference/sequence-templates/update-a-sequence-template.md): Updates an existing sequence template. `steps`, `transitions`, and `blocks` replace the current value when supplied.
- [Get Field Schemas for an Entity](https://docs.monaco.com/api-reference/schemas/get-field-schemas-for-an-entity.md): Lists the filterable and sortable fields for `entity`, one of `accounts`, `contacts`, `meetings`, `opportunities`, `sequences`, or `tasks`.
- [Get Authenticated User](https://docs.monaco.com/api-reference/auth/get-authenticated-user.md): Returns the user and organization resolved from the bearer token.
- [List Users](https://docs.monaco.com/api-reference/users/list-users.md): Returns the users in the caller's organization. Pass the optional `query` parameter to filter by substring of name or email.
- [MCP Overview](https://docs.monaco.com/mcp/overview.md)
