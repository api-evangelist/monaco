# Monaco

Monaco is an AI-native revenue platform for startups that replaces legacy CRM systems and disparate sales point solutions with a single revenue engine — unifying a contacts/accounts database, buying signals, sequences, pipeline and opportunity tracking, meeting/call recording with AI summaries, and CRO copilot coaching.

Monaco publishes a public REST API (`https://api.monaco.com`, OpenAPI 3.1) covering contacts, accounts, opportunities, tasks, tags, meetings, sequences, and sequence templates, plus a hosted OAuth-secured MCP server (`https://mcp.monaco.com/mcp`) and shipped Agent Skills. The API and MCP surface are currently in Beta.
